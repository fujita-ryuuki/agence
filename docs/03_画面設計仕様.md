## 1. 画面ごとの仕様

### S00 ログイン
- 要素：メール入力、「ログインリンクを送る」ボタン、送信後メッセージ。
- 状態：未招待メール → 「招待されていません。運用者に連絡してください」。
- 対応 FR：0 ロール。

### S01 ダッシュボード（expert）
- ヘッダー：現在の Batch（番号・状態・締め予定日）、現在のレベル（平均スコア＋到達度バー、目標 4.0）。
- カード（4枚）：未回答の疑似相談 N件／要確認の知識 N件（確信度低＋未解決の矛盾）／未評価の Agent 回答 N件／投入済みデータ（形式別件数）。各カードは該当画面へ遷移。
- 「今週の作業時間」（work_logs 集計、作業種別の内訳）。
- 空状態：Batch 0 未着手時は 3ステップガイド（領域を選ぶ→データを入れる→締め依頼）。
- 対応 FR：A-3, A-4, B-2, C-2, C-3, H5。

### S02 専門領域
- 領域マスタからのマルチセレクト（チップ表示）、自由記述テキストエリア（500字カウンタ）、保存ボタン。
- 保存後：「この設定で生成される相談の例」を 3件プレビュー（LLM 生成、保存しない）。
- 対応 FR：A-1。

### S03 データ投入
- 上部：形式タブ（PDF／PPT／テキスト／Excel／動画／Slack／E-mail）。OFF の形式はタブ非表示、設定から ON にできる。
- ファイル系タブ：ドラッグ&ドロップ領域＋ファイル選択、「匿名化する」トグル、アップロード開始。
- 動画タブ：ファイル or URL 入力、合計時間の残枠表示（上限に対する使用量バー）。
- Slack タブ：未接続→「Slack と接続」ボタン（OAuth）。接続後→チャンネル一覧（チェックボックス、公開/非公開/DM を区別、DM は折りたたみ＋注意文）、期間ピッカー、残枠表示、「取り込む」。
- E-mail タブ：未接続→「Gmail と接続」。接続後→ラベル選択、期間、送信者/受信者条件、残枠、「取り込む」。
- 下部：投入一覧テーブル（名前／形式／状態バッジ／件数・文字数／Batch／匿名化／操作：再試行・削除・文字起こしを見る）。失敗行は理由をインライン表示。
- 対応 FR：A-2, A-2-PII。

### S03a 文字起こし確認
- 左：セグメント一覧（タイムスタンプ、話者ラベル、テキスト）。テキストはインライン編集。話者名はドロップダウンで一括付け替え。
- 右：音声/動画プレイヤー（セグメントクリックでシーク）。
- 上部：「確定して整理へ渡す」ボタン、修正率表示。
- 対応 FR：A-2-TR。

### S04 疑似相談一覧
- フィルタ：未回答／回答済／後回し／スキップ／フラグ付き。Batch 切替。
- 行：相談タイトル（先頭 60字）、難易度、相談者属性、状態、所要時間。
- 「過去の実相談を持ち込む」ボタン → モーダル（テキスト貼付、匿名化トグル）。
- 対応 FR：A-3。

### S04a 疑似相談 回答
- 左：相談本文（相談者属性・状況・質問）。「自分の領域ではない」「現実的でない」フラグボタン。
- 右：回答エリア。タブ「テキスト」「音声で答える」。音声：録音ボタン（波形）、停止→文字起こし中→編集可能テキスト。
- 下部：「後回し」「スキップ」「確定して送る」。確定後はロック（再編集は operator 解除）。
- 経過時間カウンタ（work_logs）。
- 対応 FR：A-3。

### S05 知識を確認
- 上部タブ：原則／判断基準・数値ライン／診断フレーム／事例（出典層は各詳細で参照）。
- フィルタ：要確認のみ（既定 ON）、確信度スライダ、検索ボックス、Batch。
- カード：タイトル、要約 2行、確信度バッジ、出典アイコン（PDF/動画/Slack…）、レビュー状態（未確認／正しい／修正済／削除）。
- 右上：未解決の矛盾 N件 → S05b。
- 対応 FR：B-2。

### S05a ノート詳細
- 本文を意味単位で整形表示（見出し／本文／条件と判断／数値／注意点）。Markdown 記法・wikilink・frontmatter は表示しない。
- 関連ノート（層別チップ）、出典パネル（source 名＋該当箇所の抜粋、疑似相談 ID）。
- アクション：「正しい」「修正が必要」（修正テキスト入力＋理由）「削除」。
- 対応 FR：B-2, C-4（遷移先）。

### S05b 矛盾・重複・出典不明
- リスト：種別バッジ（矛盾／重複／出典不明）、対象ノート A/B の要約を左右並列、検知理由。
- アクション：「A を正とする」「B を正とする」「両方残す（条件を追記）」。
- 対応 FR：B-3。

### S06 Agent 回答を評価
- Batch 選択。評価セット一覧（相談タイトル、評価状態、最新スコア）。進捗バー（未評価 N/25）。
- 対応 FR：C-2。

### S06a 評価詳細
- 左：相談本文。中央：Agent 回答（Batch 横並びタブ：Batch0／1／2…、既定は最新）。右：根拠パネル（参照ノート一覧→クリックで S05a、元データ抜粋）。
- 下部：スコア 1〜5（ラジオ・大きめ）、減点タグ（スコア≤3 で表示・必須）、コメント、「自分ならこう答える」折りたたみ（「ブラインド比較に使われます」の注記）。
- 「原因ノートを指定して修正へ」リンク。
- 前へ／次へナビ、保存。
- 対応 FR：C-1, C-2, C-4。

### S07 レベル・推移
- KPI カード：平均スコア／合格率／スコア1比率／ブラインド勝率（目標との差分表示）。
- グラフ 1：Batch 推移（平均スコア折れ線＋合格率）。
- グラフ 2：スコア分布（Batch 別積み上げ棒）。
- グラフ 3：減点理由分布（Batch 別積み上げ棒）。
- グラフ 4：投入内容（形式別件数・文字数・回答件数）を同じ Batch 軸で。
- 作業時間の累計（種別別）。
- 対応 FR：C-3, H4, H5, H6。

### S08 設定
- 接続管理（Slack／Gmail の接続状態、切断）、形式 ON/OFF、既定の匿名化、データ削除依頼（確認モーダル）。

### R01 / R01a ブラインド比較
- 一覧：担当専門家の評価セット（相談タイトル、判定状態）。
- 詳細：相談本文、回答 A／B（左右並列・等幅・出所を示す情報なし）、判定ボタン（A優／同等／B優）、理由（必須 50字以上）、送信。
- 対応 FR：C-5。

### O01〜O07 管理
- O01：全専門家の KPI 一覧、直近ジョブ失敗、コスト累計。
- O02：専門家一覧・招待・停止、専門家詳細（投入・回答・評価の状況、作業時間）。
- O03：Batch 一覧（専門家別）、作成・締め・再生成、締め時パイプラインの進行状況（ステップごとの状態）。
- O04：ジョブ一覧（種別・状態・所要・コスト・入出力サイズ・エラー）、再実行、フィルタ。
- O05：評価セット・学習用セットの生成（条件フォーム）、プレビュー、編集、確定。
- O06：Vault ビューア（ツリー＋Markdown 表示、スナップショット切替）。
- O07：取込上限、確信度閾値、類似度閾値、モデル・プロンプトバージョン。

## 2. 共通 UI ルール
- 状態バッジ色：queued=グレー／processing=青／ready=緑／failed=赤／needs_review=琥珀。
- 確信度：0.8 以上=緑、0.6〜0.8=琥珀、0.6 未満=赤（「要確認」）。
- 破壊的操作（削除・切断・締め）は確認モーダル。
- 長時間処理はトースト＋ダッシュボードの進行表示で通知。ページ離脱可。
- 空状態には必ず次の行動ボタンを置く。
